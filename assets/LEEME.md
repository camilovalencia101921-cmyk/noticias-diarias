# Imágenes opcionales

- `portada.jpg`: foto del encabezado. Se reduce sola a menos de 150 KB y se oscurece para que el título se lea.
- `categorias/<tema>.png` o `.jpg`: reemplaza la ilustración automática de un tema.
  Nombres válidos: seguridad, orden_publico, economia, inteligencia_artificial, fenomenos_naturales,
  geopolitica, guerras, justicia, mercados, politica, ciberseguridad, energia, salud, tecnologia,
  contratacion, anime, futbol, baloncesto, freestyle, historia_antigua, local_seguridad,
  local_orden_publico, local_movilidad_servicios, local_otros.

Recuerda: el repositorio es público; no subas fotos personales.
